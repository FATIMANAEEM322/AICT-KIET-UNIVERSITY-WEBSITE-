# AICT-KIET-UNIVERSITY-WEBSITE-KIET University Website
Description

A simple university website built using HTML, CSS, and JavaScript. It includes a navigation menu, content sections,  and an interactive alert button.

How to Run
Open the project folder.
Find index.html.
Double-click the file to open it in your browser.

You can also use VS Code with the Live Server extension.

CSS
JavaScript
